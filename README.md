# 3 سنوات من الإبادة — ملف خاص من الأناضول

موقع ثابت (HTML/CSS/JS) في الذكرى الثالثة لحرب الإبادة الإسرائيلية على قطاع غزة، يُنشر على Cloudflare Pages.

- `index.html` الصفحة الرئيسية
- `embed.html` النسخة المختصرة للتضمين في موقع الأناضول (iframe بارتفاع 700px)
- `r/` صفحات التقارير
- `assets/` الخطوط والأنماط والسكربت والصور
- `_headers` إعدادات Cloudflare (السماح بالتضمين داخل aa.com.tr)

الإعداد على Cloudflare Pages: بلا أمر بناء (Build command فارغ)، ومجلد النشر هو جذر المستودع.
